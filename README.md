# Time & Chance Consultancy website

One-page static site (HTML, CSS, vanilla JS). No build step: open `index.html` or serve the folder.

- Brand colours: navy `#001838`, gold `#CAA76C`, white. Fonts: Cinzel and Montserrat (Google Fonts), matching the logo.
- Logo SVGs in `assets/` were cropped from the client's logo PDF.
- Photos in `assets/photos/` are placeholders until the client supplies real ones. Search `TODO-CLIENT` in `index.html`.
- The contact form opens the visitor's email app (mailto). There is no backend.

## Preview hosting

`render.yaml` deploys this as a free Render static site. It sends `X-Robots-Tag: noindex` so the preview is not indexed; remove that header at launch.
